# AI Real-Time Visual Intelligence System
**Project Type:** BS 4th Year Final Project  
**Tech Stack:** Python, Flask, YOLOv8, OpenCV  

## Overview
This project implements a real-time object detection system that identifies multiple objects through a live camera feed using deep learning models.

## How to Run
1. Install dependencies: `pip install ultralytics flask opencv-python`
2. Run the app: `python app.py`
3. Open `http://127.0.0.1:5000` in your browser.
